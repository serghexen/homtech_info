# AGENTS

## Обязательные правила разработки

### Структура и конфигурация
- Данные магазина, ссылки поддержки и тексты хранить в `src/config/stores.js`, а не дублировать в компонентах.
- Новый магазин добавлять отдельной конфигурацией и привязкой hostname.
- Компоненты страницы держать небольшими и отвечающими за один визуальный блок.

### Комментарии
- Для новой или изменённой неочевидной логики добавлять короткие комментарии на русском языке.
- Не комментировать очевидные присваивания и разметку.

### Проверки
- Изменение поведения должно сопровождаться обновлением или добавлением теста.
- Перед завершением любых изменений запускать `npm run check`.
- Для визуальных изменений дополнительно проверять desktop 1280 px и mobile 390 px.

### Деплой
- Production работает только через Docker Compose.
- HTTPS принимает Caddy, статические файлы отдаёт Nginx.
- Не публиковать внутренний Nginx-порт наружу и не коммитить секреты.
